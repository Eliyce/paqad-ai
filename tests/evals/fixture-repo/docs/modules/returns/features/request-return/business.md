# Request a return

Invented fixture content for testing only.

## Roles

A shopper starts a return for an item they bought. A warehouse clerk later receives and
inspects the item. A finance reviewer approves refunds above a set amount.

## Business rules

- A return can be started within 30 days of delivery.
- An item marked final sale cannot be returned.
- A refund is issued to the original payment method once the item passes inspection.
