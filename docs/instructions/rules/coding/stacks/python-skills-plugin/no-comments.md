# Python Skills Plugin No Comments

- Write no `#` comment in a Python file, except a shebang on line 1. <!-- @rule RL-d7fc -->
- Write no docstring on any module, class or function. <!-- @rule RL-d091 -->
- Write no lint or type suppression marker such as `noqa`, `type: ignore` or `pragma`. <!-- @rule RL-2bf3 -->
- Name every identifier with at least 2 characters, except `_`, `i` and `j`. <!-- @rule RL-da2e -->
- Record the reason behind a constant or design choice in `docs/`, not in the source file. <!-- @rule RL-320e -->
