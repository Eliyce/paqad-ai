# Hosts Guide

Per-host setup and support state are recorded by hand in `hosts/claude.md`, `hosts/chatgpt.md` and `hosts/codex.md`.

## Habits

- Record each host as packaged, installed or verified, with evidence, for every release (CI-19).
- Claim support in release notes only for verified hosts.
- Keep host names out of `skills/` and `shared/`; host detail belongs only in `hosts/`.
