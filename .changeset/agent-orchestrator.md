Add the Agent Orchestrator: a new or edited agent (a subagent file, a paqad stage agent or an expert persona) now goes through nine gated `paqad-ai agent` stages, from justify to release, with an agent lint, hook script tests, task-based evals with pass^k, a delegation test, host and SDK forms, tracked evidence and an `agent-<name>.json` bundle record that the end-of-change check requires. The `agent-orchestrator` seat joins the High Table, the QA expert gives a spec-compliance and a quality verdict, `paqad-ai spec pipeline experts benchmark` measures the High Table form, a delegation hook logs agent calls, and Claude Code projects are offered a cheap-tier `Explore` override.
