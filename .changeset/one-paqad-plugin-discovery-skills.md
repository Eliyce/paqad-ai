The paqad plugin now ships the product-owner skills. Start with `/paqad:start` and say what you want, or go straight to `/paqad:ask` to ask what the product does today, `/paqad:discover` to shape an idea into ready tickets, `/paqad:refine-ticket`, `/paqad:size-work` or `/paqad:plan-sprint`. They work in claude.ai chat, Cowork and Claude Code, reading your project docs and code through a connector, uploaded files or the open folder. Every skill now says where it works: `/paqad:onboard`, `/paqad:join` and `/paqad:dashboard` need Claude Code with a project folder open, and in chat they say so in one sentence. The npm package does not carry the product-owner skills; they come with the plugin.
