Seat four standing experts at every spec run and make every expert speak the project's own words.

The spec pipeline now seats a product owner, an application architect, a user-flow writer and a QA engineer on every run, alongside the specialists the detector picks. The new application-architect role says where a change lands in this app and what it is built from. Every expert brief carries a Project voice section built from the stack pack and the module docs, a deterministic voice check flags a target the project does not name, and the chief settles the word before the spec is written. The frozen spec keeps a snapshot of who contributed each line. Everything is off until the pipeline and the experts are turned on.
