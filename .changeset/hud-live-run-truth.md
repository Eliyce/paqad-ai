The HUD now tells the truth while a change is still running. A change is no longer marked failed while one of its stage helpers is still working in the background, or in the quiet gap between two stages. The band keeps the same height, only asks for your permission when a prompt is really waiting on you, and keeps showing your change while a stage runs. Finished stages read Done with a green check, the Record only lists this change, each High Table seat shows one token figure, and flags appear only once their stage has ended. Changed files are now counted from where your change actually started, so earlier work on the branch and files from a merged base branch are no longer counted as yours.
