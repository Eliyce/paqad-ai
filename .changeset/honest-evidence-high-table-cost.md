Honest gate evidence, a real acceptance-criteria-to-test check, mutation testing you can switch on, the High Table recorded and shown in the HUD, the cost of a change, and Claude Code Desktop task list and status hints. Closes #624 and #293.

- **Not required and did not run are no longer passes.** A gate that had nothing to check now says "not required", and a gate that owed a check that did not happen says "did not run", with the reason. Neither counts toward "checks held", the PR comment, the report, the receipt or the HUD, and neither is cited as compliance evidence. The quality ratchet names the measures it actually took.
- **Mutation testing is opt-in (#293).** Set `mutation_mode` to `warn` or `strict` (off by default; the team value is a floor) and call paqad's backstop from your own CI or pre-push hook. Your test command runs first, then the mutation tool you install for your stack. Under `strict` a surviving mutant fails that step. It never runs at the end of an agent turn, and the docs say what each host tier does.
- **A real acceptance-criteria-to-test check.** Each change gets its own map from the frozen spec's automated criteria to the tests changed on the branch. A criterion is proven only by a changed test that names it in a test title, a describe title or an `@obligation` tag. With no frozen spec the check reads not required; an unproven criterion fails and is named.
- **The High Table, recorded as it happens.** Each expert and the chief architect can run as its own subagent (new `paqad-expert` and `paqad-chief-architect` agents). A new `high-table.jsonl` in the change's bundle records when each seat was seated, started and finished, its budget and its exact tokens. Notes from seats that finish together are merged one role at a time, so none is lost. A table that meets after the spec is frozen is flagged and credited with no spec line.
- **The High Table in the HUD.** On the graduated and full lanes the band shows a High Table row with one dot per seat plus the chief. A live card in the chat follows the seats as they work, and a new paqad pane has a High Table tab (the round table, each seat's detail and track record, the chief's rulings and who shaped each spec line).
- **The cost of a change.** paqad adds up the tokens from the session's transcript and each paqad subagent's own transcript, for the change only, and writes `cost.json` to the bundle. Money comes from a dated price table that ships with paqad and is always labelled an estimate. The band's cost pill, `/paqad cost`, `paqad-ai status --hud` and the pane's Cost tab show the total and the split by stage, by expert and by the chief. Nothing calls a model or the network.
- **Claude Code Desktop task list and status hints (#624).** The router now tells the agent to show paqad's progress through the host's own task list, status line and needs-you flag, and to give each decision option a short preview.
