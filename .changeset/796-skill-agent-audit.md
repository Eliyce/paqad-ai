Audit paqad's own skills and agents against the skill and agent lints. `paqad-ai skill lint --all` and `paqad-ai agent lint --all` lint the whole project into one deterministic JSON report (`--report`, `--group-by rule|folder`, `--as-of`), list persona files apart, and lint the stage-agent templates after rendering them. `agent lint --all --owner-powers-as-warnings` reports the owner-permission rules (AG-015, AG-018, AG-022) as warnings, so CI blocks on every other agent finding while the permission packets and the authoring completion gate keep enforcing those three. `paqad-ai skill audit` renders `docs/instructions/tech-debt/skill-agent-audit.md` with a kept Before section and a rewritten After section. paqad's custom skill keys move under `metadata`, with JSON-shaped values in a sibling `skill.meta.yaml`; skills that still carry the old top-level keys keep working through a parser fallback that is removed in 1.117.0, and each such skill records one deprecation line.

On Claude Code, paqad's stage agents now come only from the paqad plugin. The copy in `~/.claude/agents/` is written only when the plugin is not installed, and onboarding and update remove old `paqad-*` agent files from a project's `.claude/agents/` only when their content matches an agent file paqad generated, keeping any file you edited by hand and any symlink. When neither the plugin agents nor the home copy is there, a new session shows a "stage agents are missing" message asking you to install the plugin, and paqad stops instead of running a stage in the main session. Each stage agent's record now also says how it returned (`report_status`, `report_stated`, `advance`) and lists any broken must-not rule (asking the human, writing into a feature bundle, editing outside its stage). The `dashboard`, `join`, `onboard` and `start` skills run only when you call them. Every skill script answers `--help`. A new guard stops read-only stage agents from writing files through Bash, Edit or Write anywhere except paqad's temp folders (High Table seats only in their own), and denies writes it cannot place or that come from an unknown paqad agent.
