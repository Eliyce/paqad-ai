# Site-map helper skills

The helper skills that carry the `site-map` workflow's detail. Each keeps its own procedure; the verbs in the Procedure stay the source of proof.

| Helper                                      | Job                                       |
| ------------------------------------------- | ----------------------------------------- |
| `site-map-readiness`                        | checks the run can start                  |
| `surface-extraction`, `surface-modeling`    | prove and model the surfaces              |
| `transition-tracing`, `guard-inference`     | connect surfaces and find what gates them |
| `journey-synthesis`                         | proposes the journeys                     |
| `site-map-assembly`                         | folds the layers into the map             |
| `map-verification`, `site-map-gap-analysis` | prove the map and name the gaps           |
| `finding-normalizer`                        | normalizes the findings                   |
| `site-map-retest`                           | runs the re-check for the Retest mode     |
