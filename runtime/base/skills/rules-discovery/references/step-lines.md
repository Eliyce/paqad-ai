# Step lines

One short line per step, each prefixed `**▸ paqad** · rules discovery ·`.

| Step      | Line                                                                             |
| --------- | -------------------------------------------------------------------------------- |
| start     | opened run `<run_id>` / resuming run `<run_id>` at `<step>`                      |
| inventory | `<n>` packages from `<m>` manifests: new, version-changed and removed counts     |
| decisions | `<n>` rule ideas and `<k>` not rules from resolved decisions                     |
| research  | `<n>` of `<m>` packages researched, or research skipped: no network              |
| propose   | `<n>` rows, `<k>` folded into existing rules, `<j>` still need a verdict         |
| sign-off  | Sign off N new, M changed, K removed rules?                                      |
| apply     | added, changed, removed, decisions tagged; offer to make scriptable rules checks |
| docs      | stack docs updated, then the final counts line                                   |
