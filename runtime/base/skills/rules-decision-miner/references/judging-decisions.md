# Judging decisions

| The decision                                                  | Judge it as |
| ------------------------------------------------------------- | ----------- |
| Picks a practice the team will repeat (a library, a boundary) | rule idea   |
| Several decisions pick the same practice                      | one idea    |
| Picks something for one ticket, one file or one moment        | not a rule  |
| Answers a delivery, sign-off or process question              | not a rule  |

A rule idea is one plain, testable sentence. Quote every source decision id. A not-rule gets a reason of at most one line.
