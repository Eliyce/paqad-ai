# code-prefix
# Finding-id prefixes the normalizer recognises. Each prefix scopes which

# PR — no project-side codes.

DT-       # design-test findings (design-system audit; issue #76)
HL-       # codebase-health findings (health workflow; issue #355; docs/health/<ts>.json)

SM-       # site-map findings (site-map workflow; docs/site-map/<ts>.json). id is SM-<hash8>; the SM-* names below are category values.
